Support

Something not working, or an idea for a game it should deal? Write to support@kurtesygames.com and you'll get a reply from the person who made it.

Common questions

Can the person holding the phone see everyone's name?
Not if you pass the phone around — each person taps their own name and only ever sees their own. If you send parts out by message instead, that is different: iOS always shows you a message before you send it. Switch on Keep it hidden from me and each part goes in an attached file instead of the message body, so you can post it without reading it.

Can I play without adding phone numbers?
Yes. Contact details are entirely optional. Add names only and pass the phone around the table — that is the way the app is built to be played.

Can I change the words in Imposter?
Yes, all of them. Press and hold any word set to look inside it. You can add words, sit some out for tonight without deleting them, rewrite any hint, and paste in a whole list at once. A set that came with the app can be put back exactly as it shipped from inside that same screen, and Options has a reset for all of them at once — which never touches sets you wrote yourself.

I lost a draw / a round.
Secret Santa draws are saved until you delete them, and can be archived to tidy the list. An Imposter round is deliberately not kept once you end it: the word and who had it are forgotten on purpose. Starting a new round while one is open will warn you first.

Does it need the internet?
No. HushDraw works entirely offline and has no server. Nothing you put into it is sent anywhere.

Reporting a problem

It helps to include which game you were playing, what you expected, and what happened instead — and your iOS version if you know it. If something looks wrong on screen, a screenshot is worth a lot.
