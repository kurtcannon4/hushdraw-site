HushDraw

One phone, passed around, with nobody seeing anyone else's.

HushDraw deals the secret part of a party game so a person doesn't have to. Draw names, deal a word, pass the phone. No accounts, no internet, nothing to set up.

What's in it

  • Secret SantaEveryone draws a name. Nobody draws themselves. Pass the phone around the room, or send each person their name privately.
  • ImposterEveryone gets the same word — except the imposter, who has to bluff their way through. Pick how many imposters, from none at all to everybody.
  • WerewolfSoon
  • MafiaSoon

Made to keep a secret

The whole point of a game like this is that one person doesn't end up knowing everything. So when you send someone their part, HushDraw can put it in an attached file rather than the message body — you post it without reading it. The app says plainly where that protection stops, too: whoever holds the phone is the postman, and iOS always shows the sender their own message before it goes.

Yours to change

Every word set can be opened up and edited — add words, sit some out for tonight, rewrite the hints, or write a set of your own family's inside jokes and paste it in a line at a time. The sets that ship with the app can be put back exactly as they were whenever you want.

Private by construction

There is no account, no analytics, no advertising, and no server. Everything lives on your phone. Adding someone from your contacts uses Apple's own picker, which runs outside the app — so HushDraw never gets your address book, and iOS never has to ask you for it.
